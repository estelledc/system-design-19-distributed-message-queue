# Security policy

This repository accepts only synthetic topics, principals, keys, headers, payloads, and failure traces. Do not report or attach real
credentials, customer identities, message bodies, internal broker metadata, proprietary traces, or production endpoints.

For a suspected repository vulnerability, open a GitHub security advisory when a public remote exists. Public issues are suitable
only for non-sensitive correctness bugs. This laboratory is not a deployed broker or data-processing system.
